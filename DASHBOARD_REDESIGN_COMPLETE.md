# FluFlip Dashboard Redesign — Complete

## Что сделано:

### 1. Backend — Метрики скорости бота ✅

**Добавлены новые поля в `ManagedPosition`:**
- `signal_ts` — когда сигнал был обнаружен
- `entry_latency_ms` — время от сигнала до открытия позиции (миллисекунды)
- `entry_algo` — какой алгоритм сработал (meanrev, raw_momentum, ofi и т.д.)
- `entry_score` — score сигнала при входе
- `exit_signal_ts` — когда было принято решение о выходе
- `exit_latency_ms` — время от решения до закрытия позиции (миллисекунды)

**Изменённые файлы:**
- `backend/state.py` — добавлены новые поля в ManagedPosition
- `backend/opportunity.py` — Opportunity теперь содержит algorithm и signal_ts
- `backend/paper.py` — _Quote расширен, метрики заполняются при открытии/закрытии
- `backend/real.py` — аналогично paper.py

**Как это работает:**
1. Когда алгоритм находит сигнал → записывается `signal_ts`
2. Когда позиция открывается → вычисляется `entry_latency_ms = (open_ts - signal_ts) * 1000`
3. Когда принимается решение закрыть → записывается `exit_signal_ts`
4. Когда позиция закрывается → вычисляется `exit_latency_ms = (close_ts - exit_signal_ts) * 1000`

**Это НЕ замедляет торговлю** — все вычисления происходят после действия, не до.

### 2. Frontend — Новый дизайн ✅

**Новая структура Dashboard:**
```
┌─────────────┬──────────────────────┬─────────────┐
│   Equity    │   Open Positions     │ Candidates  │
│   + Stats   ├──────────────────────┤ (sortable,  │
│             │   Recent Trades      │  search)    │
│             │   (filtered)         │             │
├─────────────┴──────────────────────┴─────────────┤
│                    Logs                           │
└───────────────────────────────────────────────────┘
```

**Open Positions — новые колонки:**
- **Algo** — какой алгоритм открыл позицию
- **Score** — score сигнала при входе
- **Age** — сколько секунд в позиции
- **Latency** — entry_latency_ms (скорость входа)

**Recent Trades — новые колонки:**
- **Algo** — алгоритм
- **Score** — score при входе
- **Entry→Fill** — entry_latency_ms (сколько мс от сигнала до открытия)
- **Exit→Close** — exit_latency_ms (сколько мс от решения до закрытия)

**Фильтры для трейдов:**
- По символу (dropdown)
- По результату (All / Profit Only / Loss Only)

**Candidates — улучшения:**
- Поиск по символу (live search)
- Сортировка по клику на заголовок (Score, z, Symbol)
- Цветовая кодировка score (зелёный = высокий, жёлтый = средний, серый = низкий)

### 3. Analytics Tab — Новая вкладка ✅

**Session Statistics:**
- Best Trade (лучший трейд)
- Worst Trade (худший трейд)
- Avg Duration (средняя длительность позиции)
- Win Rate (процент прибыльных трейдов)
- **Avg Entry Latency** (средняя скорость входа в мс)
- **Avg Exit Latency** (средняя скорость выхода в мс)

**PnL Distribution Chart:**
- Гистограмма распределения PnL по трейдам
- Показывает сколько трейдов в каждом диапазоне (-10 to -5, -5 to -2, и т.д.)

**Symbol Activity Heatmap:**
- Цветовая карта активности по символам
- Чем больше трейдов — тем ярче цвет
- Показывает топ-12 самых активных символов

**Win Rate by Hour:**
- График Win Rate по часам суток
- Показывает в какое время бот торгует лучше всего

   python -m backend.app

3. **Открыть дашборд:**
